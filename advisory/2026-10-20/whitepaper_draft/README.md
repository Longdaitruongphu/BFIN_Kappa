# One-page investment-philosophy discussion draft

This folder groups the editable text, rendered PDF, preview and renderer that formerly lived under the ambiguous `output/pdf/` path. It is an advisory discussion draft, **not** the authoritative committee memo or a newly approved policy. The renderer uses local relative paths and still works from this folder.

The text calls the 2.5% assumption “CPI inflation.” The frozen model uses a generic annual planning-inflation input of 2.5%; the December 2022 Fed PCE projections are cited as context, while no CPI or education-cost time series is fitted to obtain exactly 2.5%. Do not present the draft wording as a measured CPI forecast. See `../INDEPENDENT_ASSIGNMENT_AND_ROLE_C_AUDIT.md` and the main memo for the operative convention.
