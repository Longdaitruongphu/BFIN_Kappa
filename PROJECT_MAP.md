# Kappa project map

Start with `CODEX_HANDOFF.md` for the original-case state and `ADVISORY_HANDOFF.md` for later work. The authoritative case is `reference/BFIN-WS2026-Group_Assignment.pdf`. The saved decision is `policy/frozen_policy.json`; neither the case nor this policy should be rewritten using 2023–25 outcomes.

| Place | What belongs there | Status / handling |
| --- | --- | --- |
| `reference/` | Assignment and the unchanged Role C attachment copy | Source material; do not treat workbook text as case instructions |
| `data/raw/` | Saved Yahoo daily CSV/pickle downloads, French ZIPs, download manifest and supporting source record | Keep byte-for-byte; never silently refresh |
| `data/processed/` | Month-end prices, monthly returns and FF3 slices generated from raw | Recreated by offline rebuild |
| `analysis/` | Retrieval code, numerical model, reports and independent audit scripts | Main offline entry point: `analysis/rebuild.py` |
| `policy/` | Frozen original policy and decision record | Preserve original SHA-256 |
| `outputs/tables/` and `outputs/figures/` | Named analytical evidence used in the memo/slides | Generated, traceable through `EVIDENCE_MAP.md` |
| `outputs/role_c_audit/` | Read-only comparison and verification receipts | Audit evidence, not an input to the frozen strategy |
| `deliverables/` | Committee memo, initial record, presentation and requirements guide | Prepared original-case artifacts; submission itself unverified |
| `initial_submission/` | Prepared dated initial submission snapshot | Preserve separately from any actual upload record |
| `advisory/YYYY-MM-DD/` | Later consultation, white-paper drafts and current audit/runbook | Not a replacement for original policy |
| `docs/` | Team-planning documents and their builders | Internal coordination; see `docs/README.md` |
| `checkpoint_history/` and `logs/` | Continuation receipts, errors and dated snapshots | Keep for reproducibility |
| `.slide_build/` | Editable slide validation and rendered images | Build evidence; do not confuse with final PDF/PPTX |
| `.venv/` | Local Python packages (about 422 MB, ignored by Git) | Needed for immediate offline rebuild; recreate from `requirements-analysis.txt` on another machine |

The former ambiguous `output/pdf/` folder contained only a **discussion draft** of the one-page philosophy. It is now grouped at `advisory/2026-10-20/whitepaper_draft/`, with its source, PDF, preview and renderer together. Canonical model outputs remain exclusively under `outputs/`.
